### **NestJS 요청 라이프사이클 순서**

1. **클라이언트 요청 (Request)**
   - 클라이언트가 서버에 요청을 보냅니다. 이 요청은 HTTP 요청으로, 예를 들어 사용자가 특정 데이터에 접근하거나 리소스를 수정하는 API 호출일 수 있습니다.
2. **Middleware (미들웨어)**
   - **미들웨어**는 요청(Request)을 처음으로 처리하는 단계입니다. 요청을 가로채고, 로그를 기록하거나 요청을 변형하는 등의 작업을 수행합니다. 미들웨어는 주로 모든 요청에 대해 공통적으로 적용해야 하는 작업(예: 인증, 로깅)을 처리할 때 사용됩니다.
   - 요청은 이 단계에서 통과되거나, 경우에 따라 특정 조건에 맞지 않으면 여기서 종료될 수 있습니다.
3. **Guard (가드)**
   - \*가드(Guard)\*\*는 요청을 특정 핸들러에 전달하기 전에 요청이 유효한지 확인합니다. 주로 인증 또는 권한 확인을 담당합니다. 요청을 허용할지 거부할지 결정하는 역할을 합니다.
   - 사용자가 적절한 권한을 갖고 있는지를 검사하고, 그렇지 않으면 요청을 차단합니다.
4. **Interceptor (인터셉터 - 요청 전처리)**
   - **인터셉터**는 가드 이후에 위치하며, 요청 전/후에 실행되는 로직을 처리합니다. 요청을 가로채서 전처리할 수 있으며, 응답이 돌아오기 전에도 후처리를 수행할 수 있습니다.
   - 예를 들어, 요청이 컨트롤러로 전달되기 전에 로깅을 하거나 데이터 변형을 할 수 있습니다. 요청 흐름의 모든 단계에서 로직을 삽입하기에 적절한 위치입니다.
5. **Pipe (파이프)**
   - \*파이프(Pipe)\*\*는 요청 데이터의 유효성 검사와 변환을 담당합니다. 클라이언트가 전송한 데이터가 올바른 형식인지 확인하고, 필요시 데이터를 변환하여 컨트롤러로 전달합니다.
   - 예를 들어, 문자열을 숫자로 변환하거나, 특정 객체 형태로 매핑하는 데 사용됩니다. 파이프는 요청이 유효한 형식인지 검사하고, 변환하여 사용하기 쉽게 만드는 데 도움을 줍니다.
6. **Controller (컨트롤러)**
   - **컨트롤러**는 요청을 받아 실제로 처리할 핸들러로 연결하는 역할을 합니다. 클라이언트 요청을 분석하고, 해당하는 서비스로 요청을 전달합니다.
   - 각 요청은 특정 경로(route)에 연결되며, 그에 맞는 비즈니스 로직을 실행하도록 `Service`를 호출합니다.
7. **Service (서비스)**
   - \*서비스(Service)\*\*는 비즈니스 로직을 처리하는 곳입니다. 데이터베이스와의 통신 또는 특정 로직을 수행하여 데이터를 가공하거나, 계산 등의 핵심 기능을 담당합니다.
   - 컨트롤러는 서비스를 호출하여 비즈니스 로직을 처리하고, 그 결과를 반환합니다.
8. **Repository (레포지토리)**
   - \*레포지토리(Repository)\*\*는 데이터베이스와 상호작용하는 계층입니다. 데이터 조회, 삽입, 수정, 삭제 등을 처리합니다. ORM을 사용할 경우 데이터를 저장하거나 불러오는 역할을 합니다.
   - 서비스 계층은 주로 레포지토리를 이용해 데이터를 조회하거나 갱신하며, 이 과정에서 데이터의 영속성을 유지합니다.
9. **Exception Filter (예외 필터)**
   - 요청을 처리하는 중간에 발생하는 모든 예외 상황을 처리합니다. 예외가 발생하면 이 필터를 통해 에러 메시지와 응답 코드를 정의하고 클라이언트로 반환합니다.
   - 예를 들어, 인증 실패나 잘못된 입력 데이터 등으로 인해 발생한 예외가 컨트롤러에서 발생하면 예외 필터가 이를 캐치하여 적절한 형식으로 클라이언트에 응답합니다.
10. **Interceptor (응답 후처리)**
    - **인터셉터**는 요청이 처리된 후에도 실행됩니다. 컨트롤러에서 응답이 생성된 후, 이를 가로채어 응답을 변형하거나 후처리할 수 있습니다.
    - 예를 들어, 응답 데이터를 특정 포맷으로 변환하거나, 로그를 기록할 수 있습니다.
11. **응답 (Response)**
    - 최종적으로 처리된 데이터가 클라이언트에게 응답으로 반환됩니다. 클라이언트는 이를 받아 화면에 데이터를 표시하거나 후속 작업을 진행합니다.

### 정리

NestJS의 요청 라이프사이클은 다음과 같이 순서대로 흐릅니다:

1. **Request (요청)**
2. **Middleware (미들웨어)**
3. **Guard (가드)**
4. **Interceptor (인터셉터 - 요청 전처리)**
5. **Pipe (파이프)**
6. **Controller (컨트롤러)**
7. **Service (서비스)**
8. **Repository (레포지토리)**
9. **Exception Filter (예외 필터)**
10. **Interceptor (인터셉터 - 응답 후처리)**
11. **Response (응답)**
