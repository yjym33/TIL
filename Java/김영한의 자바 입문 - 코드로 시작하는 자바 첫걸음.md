## 김영한의 자바 입문 - 코드로 시작하는 자바 첫걸음

출처 : 김영한의 자바 입문 - 코드로 시작하는 자바 첫걸음

## 1. 자바란 무엇인가? & 자바의 특징

### 자바란?

자바는 1995년 선마이크로시스템스에서 개발한 객체지향 프로그래밍언어이다.

### 자바의 특징

- **플랫폼 독립성**자바가 플랫폼 독립성 특징을 가질 수 있는 이유는 **자바 가상 머신(Java Virtual Machine, JVM)**과 **바이트 코드(Byte Code)** 때문이다. 자바 컴파일러는 자바 소스 코드를 컴파일하여 바이트 코드로 된 **클래스 파일(.class)**을 생성하고 생성된 파일은 자바 가상 머신이 **인터프리터** 방식으로 실행시킨다. 따라서 운영체제 상관없이 실행 가능하다.
- **객체 지향**자바는 객체 지향 언어로서 **캡슐화, 상속, 다형성, 추상화**를 완벽하게 지원한다.객체 지향 언어는 **유지보수**가 쉽고 **확장성**이 용이하다.
- **멀티스레드**하나의 자바 프로그램이 멀티스레드를 지원하지 않는 운영체제에서도 **다수의 작업을 처리**할 수 있도록 **다수의 스레드**가 동시에 실행할 수 있는 환경을 지원한다.
- **가비지 컬렉터(Garbage Collector, GC)**자바가 개발자를 대신해 메모리를 직접 관리한다.객체를 생성할 때 자동으로 메모리 영역을 찾아서 할당하고 사용하지 않는 객체는 **Garbage Collector를 실행해 자동으로 객체를 제거**해준다.

## 2. 변수

### 변수 선언과 초기화

변수의 선언과 초기화를 각각 따로 할 수도 있고 선언과 동시에 초기화를 할 수도 있다.

```java
int a; //변수 선언
a = 100; //변수 초기화

int b = 200; //변수 선언과 초기화를 동시에
```

### 리터럴

개발자가 코드에 직접 적은 고정된 값을 리터럴(literal)이라고 한다.

```java
int a = 10; //정수 리터럴
double b = 11.5; //실수 리터럴
boolean c = true; //불리언 리터럴
char d = 'A'; //문자 리터럴
String e = "Hello World!"; //문자열 리터럴
```

### 리터럴 타입 지정

- 정수 리터럴은 int타입을 기본으로 사용한다. int타입 범위를 넘어가면 L을 붙여 long타입으로 변경해야 한다. (이때 대문자 L, 소문자 l 모두 가능하지만 가독성때문에 대문자 L을 추천)
- 실수 리터럴은 double타입이 기본이다. (float은 잘 안씀)

### 변수 명명 규칙

- 숫자로 시작할 수 없다.
- 공백이 들어갈 수 없다.
- 예약어를 사용할 수 없다.
- 영문자, 숫자, 달러 기호, 밑줄만 사용할 수 있다.
- 소문자로 시작하고 이후 단어는 대문자를 사용한다. (낙타표기법 or Camel Case)

## 3. 연산자

### 문자열 더하기

자바는 문자열에 + 연산자를 사용하면 두 문자열을 연결할 수 있다.

### 연산자 우선순위

우선순위는 2가지만 기억하자.

- 상식선에서 우선순위를 생각하자.
- 애매하면 괄호( )를 사용하자.

### 증감 연산자

++a : 증감 연산자가 앞에 있다고 해서 전위 증감 연산자라 한다.

a++ : 증감 연산자가 뒤에 있다고 해서 후위 증감 연산자라 한다.

```java
//전위 증감 연산자 사용 예시
int a = 1;
int b = 0;
b = ++a; //a의 값을 먼저 증가시키고, 그 결과를 b에 대입
System.out.println(a, b);
결과 : a = 2, b = 2

//후위 증감 연산자 사용 예시
int a = 1;
int b = 0;
b = a++; //a의 값을 b에 먼저 대입하고, 그 후 a값을 증가
System.out.println(a, b);
결과 : a = 2, b = 1
```

단, 증감 연산자를 단독으로 사용하는 경우에는 다른 연산이 없기 때문에 본인의 값만 증가한다.

따라서 전위이든 후위이든 둘다 결과가 같다.

## 4. 조건문

### if문

if문은 특정 조건이 참인지 확인하고, 그 조건이 참일 경우에 실행한다.

```java
if (condition) {
	//조건이 참일 경우 실행되는 코드
}
```

### else문

else문은 if문에서 만족하는 조건이 없을 경우 실행한다.

```java
if (condition) {
	//조건이 참일 경우 실행되는 코드
} else {
	//만족하는 조건이 없을 경우 실행되는 코드
}
```

### else if문

else if문은 앞선 if문의 조건이 거짓일 때 다음 조건을 검사한다.

만약 앞선 if문이 참이라면 else if를 실행하지 않는다.

```java
if (condition1) {
	//조건1이 참일 경우 실행되는 코드
} else if (condition2) {
	//조건1이 거짓이고, 조건2가 참일 경우 실행되는 코드
} else {
	//모든 조건이 거짓일 때 실행되는 코드
}
```

### switch문

switch문은 조건식에 해당하는 특정 값으로 실행할 코드를 선택한다.

```java
switch (condition) {
	case var1:
    	//조건식의 결과 값이 var1일 경우 실행되는 코드
    	break;
    case var2:
   		//조건식의 결과 값이 var2일 경우 실행되는 코드
    	break;
    default:
    	//조건식의 결과 값이 위의 어떤 값에도 해당하지 않을 경우 실행되는 코드
```

### 삼항 연산자

삼항 연산자는 항이 3개라는 뜻이다. 조건, 참표현식, 거짓표현식 이렇게 항이 3개이다.

```java
(조건) ? 참표현식 : 거짓표현식
```

## 5. 반복문

### while문

while문은 조건에 따라 코드를 반복해서 실행할 때 사용한다.

- 조건식을 확인한 후, 참이면 실행하고 거짓이면 while문을 벗어난다.
- 이후에 코드 블럭이 끝나면 다시 조건식 검사로 돌아가서 조건식을 검사한다.(무한 반복)

```java
while (condition) {
	//코드
}
```

### do-while문

do-while문은 최초 한번은 꼭 실행해야 하는 경우에 사용한다.

```java
do {
	//코드
} while (condition);
```

### for문

for문은 주로 무한 반복이 아닌 반복 횟수가 정해져 있을 때 사용한다.

```java
for (초기식; 조건식; 증감식;) {
	//코드
}
```

### 중첩 반복문

반복문 내부에 또 반복문을 사용할 수 있다. for, while 둘다 가능하다.

### break, continue

- break문은 반복문을 즉시 종료하거나 switch문을 종료할 때 쓴다.
- 반복문에서 break문은 주로 if문과 함께 사용한다. if문의 조건에 따라 반복문의 종료 여부를 결정한다.
- 만약 중첩 반복문에서 사용할 경우 내부 반복문만 종료하고 외부 반복문은 실행한다.
- continue문은 반복문의 나머지 부분을 건너뛰고 반복문의 조건식으로 이동하여 반복을 실행한다.
- continue문도 주로 if문과 함께 사용한다. if문의 조건에 따라 반복문의 나머지 부분을 건너뛸지 말지 결정한다.

## 6. 스코프, 형변환

### 지역 변수와 스코프

- 변수는 선언한 위치에 따라 지역 변수, 멤버 변수(클래스 변수, 인스턴스 변수)와 같이 분류된다.
- 지역 변수는 말 그대로 특정 지역에서만 사용할 수 있는 변수이다. (특정 지역을 벗어나면 사용 불가)

```java
public static void main(String[] args) {
	int a = 1; //a 생존 시작
    if (true) {
    	int b = 2; //b 생존 시작
        System.out.println(a); //내부에서 외부로는 접근 가능
        System.out.println(b);
    } //b 생존 종료

    //System.out.println(b); //오류, 변수 b에 접근 불가
    System.out.printlb(a); //변수 a는 아직 생존 중이므로 접근 가능
} //a 생존 종료
```

변수 a는 main{ } 코드 블록 안에서 선언되었기 때문에 main{ }의 코드 블록이 종료될 때 까지 생존한다.

변수 b는 if{ } 코드 블록 안에서 선언되었기 때문에 if{ }의 코드 블록이 종료될 때 까지 생존한다.

이렇듯 변수의 접근 가능 범위를 스코프(Scope)라 한다.

### 스코프 존재 이유

비효율적인 메모리 사용과 코드 복잡성을 줄이고 효율적인 메모리 사용과 유지보수하기 좋다는 점이다.

### 자동 형변환

작은 범위에서 큰 범위로는 값을 넣을 수 있다.

ex) int -> long -> double

큰 범위에서 작은 범위로는 값을 넣을 수 없다.

ex) double -> long -> int

### 명시적 형변환

큰 범위에서 작은 범위로 값을 넣을 때는 개발자가 **직접 형변환**을 해주는 명시적 형변환이 필요하다.

```java
double a = 2.5;
int b = 0;

//b = a; //컴파일 오류
b = (int) a; //형변환
System.out.println(b);
```

형변환은 바꾸고 싶은 데이터 타입을 (int)와 같이 괄호를 사용해서 바꾸면 된다.

int타입은 정수만 표현하기 때문에 2가 출력된다.

## 7. Scanner

### Scanner 클래스

- System.out으로 출력을 했다면 System.in으로 입력을 받을 수 있다.
- Scanner 클래스는 new라는 키워드를 써서 객체를 생성해야 사용할 수 있다.

```java
Scanner scanner = new Scanner(System.in)
```

자바는 라이브러리에서 다양한 클래스를 제공해주기 때문에 사용하려면 **import**문장을 이용해

**java.util 패키지**에 존재하는 **Scanner 클래스를 호출**해줘야 한다.

```java
import java.util.Scanner; //java.util 패키지에 존재하는 Scanner 클래스
import java.util.*; //java.util 패키지에 존재하는 모든 클래스
```

## 8. 배열

### 배열의 선언과 생성

- 같은 타입의 변수를 반복해서 선언하고 사용하는 문제를 간단하게 해결하는 것이 배열이다.
- 배열을 생성하면 자바가 배열의 참조값을 반환해주고 이 참조값을 통해 실제 배열에 접근하고 사용할 수 있다.
- 자바는 배열을 생성할 때 그 내부값을 **자동으로 초기화**한다. (숫자는 0, boolean은 false, String은 null)

```java
int[] arrays; //배열 선언
arrays = new int[5]; //int타입의 배열 5개 생성

int[] arrays = new int[5]; //배열의 선언과 생성을 동시에
```

### 배열 사용

- 배열을 사용하려면 사이에 숫자를 넣어주면 된다.
- 배열의 위치를 나타내는 숫자를 **인덱스(index)**라 한다.

```java
arrays[0] = 1;
arrays[1] = 2;
arrays[2] = 3;
arrays[3] = 4;
arrays[4] = 5;
```

int타입 배열을 5개 만들었다면 인덱스는 0부터 4까지 존재한다.

따라서 인덱스의 사용 범위는 0 ~ (n-1)이 된다. (배열을 10개 만들면 인덱스 범위는 0 ~ 9)

### 2차원 배열

- 2차원 배열은 int[ ]arrays = new int[2][3]와 같이 선언하고 생성한다.
- arrays[2][3]와 같이 사용하는데 행(row) 번호를 먼저 찾고 그 다음에 열(column) 번호를 찾는다.
- arrays[행][열], arrays[row][column]

```java
arrays[0][0] = 1; //0행, 0열
arrays[0][1] = 2; //0행, 1열
arrays[0][2] = 3; //0행, 2열
arrays[1][0] = 4; //1행, 0열
arrays[1][1] = 5; //1행, 1열
arrays[1][2] = 6; //1행, 2열
```

### 향상된 for문

- 향상된 for문은 배열을 사용할 때 편리하게 사용할 수 있다.
- 각각의 요소를 탐색한다는 의미로 **for-each문**이라고도 부른다.

```java
for (변수 : 배열) {
	//배열의 요소를 반복 수행할 코드
}
```

## 9. 메서드

### 메서드 사용

- 자바에서는 함수를 **메서드**라 한다. (함수의 한 종류)
- 메서드를 정의할 때 **메서드 선언**과 **메서드 본문**으로 나눌 수 있다.

```java
public static int add(int a, int b) //메서드 선언 {
	//메서드 본문
}
```

### 메서드 용어정리

```java
add(10, 20); //메서드 호출

public static int add(int a, int b) {

} //메서드 정의
```

호출할 때 10, 20처럼 넘기는 값을 **Argument,인수,인자**라 한다.

정의할 때 선언한 변수인 int a, int b를 **Parameter, 매개변수**라 한다.

### 메서드 정의

메서드는 다음과 같이 정의한다.

```java
public static int add(int a, int b) {
	//메서드 본문
}

제어자 반환타입 메서드이름(매개변수명) {
	//메서드 본문
}
```

**제어자** : public , static 과 같은 부분이다.

**반환 타입** : 메서드가 실행 된 후 반환하는 데이터의 타입을 지정한다. (반환 타입이 있으면 return 사용)

**메서드 이름** : 메서드의 이름이다. 이 이름은 메서드를 호출하는 데 사용된다.

**매개변수** : 입력 값으로, 메서드 내부에서 사용할 수 있는 변수이다.

**메서드 본문** : 실제 메서드의 코드가 위치한다.

### 메서드 오버로딩

- 하나의 메서드로 여러 기능을 사용할 때 쓴다.
- 같은 클래스 내에서 메서드 **이름이 같아도** 매개변수의 **개수 혹은 타입이 다르면** 오버로딩을 할 수 있다.
- **반환 타입은 인정하지 않는다**.

오버로딩 성공 예시)

```java
add(int a, int b)
add(int a, int b, int c) //매개변수 개수가 다름
add(double a, double b) //매개변수 타입이 다름
```

오버로딩 실패 예시)

```java
int add(int a, int b)
double add(int a, int b) //반환 타입이 다르지만 매개변수 개수, 타입이 같음
```
